📝 Bộ đề của thầy cô

Soạn câu hỏi theo bài đang học: gõ tay, nhập từ Excel (CSV), tạo tự động từ PDF / Word / ảnh trang SGK (có thể dùng AI), rồi bấm Chia sẻ để lấy mã. Giao bộ đề cho lớp ở 🏫 Server lớp học → ⚙️ Cài đặt server. Bộ đề lưu trên máy này.

＋ Tạo server lớp mới

Cách dùng
  1. Tạo server lớp → đọc / chiếu mã server cho học sinh (hoặc tạo sẵn tài khoản + PIN để in phát).
  2. Học sinh vào trò chơi → 👤 Tài khoản → đăng nhập → nhập mã lớp. Mỗi lớp có tiến trình riêng, tự lưu trên mạng.
  3. ⚙️ Cài đặt server: chọn khối lớp & môn học, giao 📝 Bộ đề, chọn cách vào lớp.
  4. Xem tiến độ học tập, quản lý trò chuyện của lớp ở đây.
Chọn một server lớp bên trái hoặc tạo server mới.
