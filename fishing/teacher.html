Câu Cá Học Giỏi 🎣 Vào trò chơi

Server lớp học của tôi

Đang tải…

＋ Tạo server lớp mới

Cách dùng
  1. Tạo server lớp → đọc / chiếu mã server cho học sinh (hoặc tạo sẵn tài khoản + PIN để in phát).
  2. Học sinh vào trò chơi → 🌐 Server → nhập mã, tên, PIN. Mỗi server có tiến trình riêng, tự lưu trên mạng.
  3. Xem tiến độ học tập, quản lý trò chuyện của lớp ở đây.
Chọn một server lớp bên trái hoặc tạo server mới.
